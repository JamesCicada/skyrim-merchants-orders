# Merchant Orders

A Skyrim Anniversary Edition mod prototype for ordering common materials from city merchants.

## 0.3.0

- Eleven merchants, six common materials, and merchant specialties.
- Editable order quantities: 1-500 units.
- Adjustable quantity-based sourcing times: 0.25x-4x.
- Free merchant pickup or vanilla courier delivery for 5% extra.
- Itemized quote, persistent order tracking, and one-time receipt-based delivery.
- Courier recovery through the original merchant, with a one-time delivery-fee refund.
- Optional UIExtensions menus and SkyUI MCM in a separate addon.

[Installation and gameplay](docs/INSTALL.md) | [UI dependencies](docs/UI.md) | [Nexus listing details](docs/NEXUS_PUBLISHING.md)

Installable core/addon ZIPs are generated by build.ps1 under dist/; build outputs are not committed to this source repository.

The core needs only Skyrim.esm/vanilla scripts. The UI addon needs SKSE, SkyUI SE, and UIExtensions SE. Dependency files are not bundled.

Existing paid pickup orders retain their terms. New settings never rewrite accepted orders. One outstanding order remains the limit. No rare materials or equipment are sold.

Author-tested in game on 30 October 2026: the author reports the current mod working, with occasional courier delays. Sourcing time does not include the courier finding you. Seven scripts compile and both plugins/package allowlists pass build checks. Compatibility across every runtime and load order is not established.
