# Merchant Orders 0.4.0 - local development notes

Not yet tested in game or published.

- Enhanced addon generates catalogs from current trade inventory.
- Common material allowlist plus ordinary food/drink.
- Standard innkeepers/merchants discovered through vendor factions/chests, including Orgnar's setup.
- Supports properly flagged mod-added food; additional materials need an allowlist patch.
- Rare materials, equipment, poison/hostile consumables, and known special/drug items filtered out.
- Dynamic itemized quotes, payment revalidation, and food-capable saved orders.
- Existing core IDs and original saved-field types preserved.
- Existing settings, 5% courier delivery, and pickup recovery retained.

Install matching core and enhanced 0.4.0 archives with SKSE, SkyUI SE, and UIExtensions SE for dynamic mode. Core alone keeps the older fixed material catalogs.

Current stock determines availability; sold-out food may be absent until restock. Horker Stew qualifies when actually stocked, rather than being forcibly offered by every innkeeper.

Build checks pass; the new runtime paths remain for periodic testing. Released 0.3.0 remains unchanged.
