# Merchant Orders and Deliveries 0.3.0

Author-tested early release for Skyrim Special Edition / Anniversary Edition.

## Downloads

- MerchantOrders-0.3.0-prototype.zip: required core mod. Includes basic menus; no SKSE/SkyUI/UIExtensions requirement.
- MerchantOrders-UI-0.3.0.zip: optional enhanced menus and MCM. Requires the matching core, SKSE, SkyUI SE, and UIExtensions SE.
- SHA256SUMS.txt: checksums for both mod archives.

Install through MO2 or Vortex. Enable MerchantOrders.esp; for the addon, enable MerchantOrders-UI.esp after it.

## Features

- Eleven merchants across the five major cities.
- Six common materials, with separate blacksmith/general catalogs.
- Editable quantities of 1-500 and sourcing multipliers of 0.25x-4x.
- Free merchant pickup or courier delivery for 5% extra, rounded up.
- Itemized quotes, order status, voiced trade dialogue, and vendor payments.
- Courier-to-pickup recovery with delivery-fee refund.
- Optional UIExtensions lists, direct quantity entry, and SkyUI MCM.

One outstanding order globally. No rare materials or equipment.

## Testing and known limits

The author reports 0.3.0 working in game. Couriers can sometimes arrive late: the sourcing estimate excludes the courier finding you. Pickup recovery is available through the original merchant once sourcing is complete.

Compilation, plugin links, record-ID preservation, fee rounding, and package checks pass. Testing does not establish every runtime, load-order, or save-upgrade combination. Merchant-death recovery is not implemented.

Existing paid pickup orders keep their original terms. Quit Skyrim before replacing the plugin and packaged scripts together; do not reset the order quest.

## Optional UI dependencies
